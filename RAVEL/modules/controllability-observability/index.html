Controllability and Observability · Pole Placement and Observers

Test state access with rank and PBH conditions, place feedback and observer poles, and distinguish full controllability from stabilizability and detectability.

advancedFunctionalReading lesson

Which internal modes can inputs move and measurements reveal, and how does that determine feedback design?

Access is about modes, not sensor or actuator count

For a continuous-time LTI model, controllability asks whether inputs can move the state between arbitrary points in finite time. Observability asks whether the initial state can be uniquely inferred from a known input and measured output history over a finite interval.

One actuator may control several states through dynamics, and one sensor may reveal several states over time. Counting actuators or measured coordinates is therefore not a rank test.

For nnn states,

C=[BAB⋯An−1B],O=[CCA⋮CAn−1].\begin{aligned} \mathcal{C}&=\begin{bmatrix}B&AB&\cdots&A^{n-1}B\end{bmatrix},\\ \mathcal{O}&=\begin{bmatrix}C\\CA\\\vdots\\CA^{n-1}\end{bmatrix}. \end{aligned}CO​=[B​AB​⋯​An−1B​],=​CCA⋮CAn−1​​.​

Controllability requires rank⁡C=n\operatorname{rank}\mathcal{C}=nrankC=n; observability requires rank⁡O=n\operatorname{rank}\mathcal{O}=nrankO=n. These properties are unchanged by an invertible state-coordinate transformation. Known feedthrough DuD\mathbf{u}Du can be subtracted from measurements, so DDD does not alter this observability test.

The equivalent PBH tests are

rank⁡[λI−AB]=n,rank⁡[λI−AC]=n,\begin{aligned} \operatorname{rank}\begin{bmatrix}\lambda I-A&B\end{bmatrix}&=n,\\ \operatorname{rank}\begin{bmatrix}\lambda I-A\\C\end{bmatrix}&=n, \end{aligned}rank[λI−A​B​]rank[λI−AC​]​=n,=n,​

for every eigenvalue λ\lambdaλ of AAA, using complex rank where needed. Testing other λ\lambdaλ adds nothing because λI−A\lambda I-AλI−A is then already invertible. PBH isolates specific inaccessible modes rather than merely reporting a deficient total rank.

Worked example: actuate acceleration, measure position

An ideal unit-mass double integrator has one acceleration input and one measured position:

Read the diagram. One input reaches two states through time evolution: it changes velocity first and position subsequently. One position sensor also reveals two states over time, because velocity is position’s slope. Each integrator carries its initial value. This access through dynamics explains why actuator and sensor counts do not establish rank; it does not prescribe differentiating noisy sensor data.

Estimate the missing velocity

Read the diagram. The observer predicts with the known input and corrects that prediction using the mismatch between measured and predicted position. Its estimated position and velocity feed the controller. In this exact nominal example, feedback poles −2,−3-2,-3−2,−3 and observer error poles −8,−9-8,-9−8,−9 appear together in the augmented system; faster observer correction also raises sensitivity to measurement noise.

Their block-triangular matrix has the union of feedback poles and observer poles: −2,−3,−8,−9-2,-3,-8,-9−2,−3,−8,−9. This is the continuous-time LTI separation principle under the nominal model. Faster observer poles can improve initial error decay but increase noise sensitivity and gain; they do not guarantee a better real measurement system.

Observability of (A,C)(A,C)(A,C) equals controllability of (AT,CT)(A^\mathsf{T},C^\mathsf{T})(AT,CT). This duality converts a pole-placement calculation for the transposed pair into an observer gain. See the author’s state-feedback and output-feedback chapters.

Weaker properties can still permit stabilization

Stabilizability requires every uncontrollable mode to be strictly stable. Detectability requires every unobservable mode to be strictly stable. Equivalently, the respective PBH test need only hold at eigenvalues with Re⁡λ≥0\operatorname{Re}\lambda\geq0Reλ≥0.

For A=diag⁡(−1,2)A=\operatorname{diag}(-1,2)A=diag(−1,2), B=[0,1]TB=[0,1]^\mathsf{T}B=[0,1]T and C=[0,1]C=[0,1]C=[0,1], the first mode is inaccessible but already decays. The pair is stabilizable and detectable without being fully controllable or observable.

For the double integrator with velocity-only measurement C=[0,1]C=[0,1]C=[0,1], observability rank falls to one. Absolute position is an unobservable zero mode; it does not decay, so this pair is not detectable for asymptotic state estimation.

Oral practice

  • Can feedback move an uncontrollable pole? No. It can only shape the controllable part.
  • Can an observer reconstruct an unobservable unstable mode? No; detectability is the minimum requirement for asymptotically decaying estimation error.
  • Does formal full rank ensure a well-conditioned numerical design? No. Nearly dependent directions can make rank decisions, gains and estimates sensitive to uncertainty and scaling.

Relate these hidden modes to transfer functions and evaluate the designed loop using stability and performance.

Check your understanding

  • Distinguish stabilizability and detectability from full-state access.
  • Calculate state-feedback and observer gains for two states.
  • Explain observer duality and the linear separation principle.
