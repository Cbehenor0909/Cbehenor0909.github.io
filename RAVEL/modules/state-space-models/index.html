State-Space Models · From an ODE to States

Choose states, inputs and outputs, convert higher-order ODEs into first-order equations, and linearize about a stated operating point.

intermediateFunctionalReading lesson

Which variables must be retained to predict a system's future from its present state and input?

A state contains memory

Position alone cannot predict a moving mass’s next position: velocity is also needed. A state collects enough independent variables that its current value, together with future inputs, determines future evolution. For a mass, position and velocity are natural states. In a circuit, capacitor voltages and inductor currents often serve that role.

An input is an externally specified signal. An output is the quantity observed or controlled. These roles must be stated before writing matrices: displacement, velocity and acceleration outputs produce different C,DC,DC,D even when the underlying mechanics is identical.

For a finite-dimensional linear time-invariant model,

x˙=Ax+Bu,y=Cx+Du.\dot{\mathbf{x}}=A\mathbf{x}+B\mathbf{u},\qquad \mathbf{y}=C\mathbf{x}+D\mathbf{u}.x˙=Ax+Bu,y=Cx+Du.

If there are nnn states, ppp inputs and rrr outputs, then AAA is n×nn\times nn×n, BBB is n×pn\times pn×p, CCC is r×nr\times nr×n and DDD is r×pr\times pr×p. These dimensions are a useful first error check.

Higher-order equations and coordinate choices

For an ODE with no input derivatives,

q(n)+an−1q(n−1)+⋯+a1q˙+a0q=b0u,q^{(n)}+a_{n-1}q^{(n-1)}+\cdots+a_1\dot q+a_0q=b_0u,q(n)+an−1​q(n−1)+⋯+a1​q˙​+a0​q=b0​u,

choose x=[q,q˙,…,q(n−1)]T\mathbf{x}=[q,\dot q,\ldots,q^{(n-1)}]^\mathsf{T}x=[q,q˙​,…,q(n−1)]T. The first n−1n-1n−1 equations shift to the next state; the last equation uses the ODE. If the ODE contains u˙\dot uu˙ or higher input derivatives, this naive choice requires differentiated inputs. A proper transfer-function realization can instead use internal states that avoid demanding those derivatives.

States are not unique. If z=Tx\mathbf{z}=T\mathbf{x}z=Tx with TTT invertible,

Az=TAT−1,Bz=TB,Cz=CT−1,Dz=D.\begin{aligned} A_z&=TAT^{-1},&B_z&=TB,\\ C_z&=CT^{-1},&D_z&=D. \end{aligned}Az​Cz​​=TAT−1,=CT−1,​Bz​Dz​​=TB,=D.​

The matrices change, but the input/output behavior and eigenvalues do not. A realization may also include redundant states; a minimal realization retains only controllable and observable dynamics.

Oral practice

  • Can output equal state? Yes, but it need not. A single sensor may observe a combination of several states.
  • Why write perturbation variables? The linear equations describe deviations around an operating point, rather than the original variables at an arbitrary origin.
  • Does choosing states determine the physics? The physical model determines the dynamics; a valid state choice represents its memory. A convenient coordinate change does not add or remove physical behavior.

Next derive the model’s transfer function and check which states can be actuated or estimated in controllability and observability.

Check your understanding

  • Convert a mechanical second-order ODE to a first-order state model.
  • Identify input, output and direct feedthrough with units.
  • Explain nonunique state coordinates and similarity transformations.
  • Linearize a nonlinear model around an equilibrium.
